# 灵犀 Canvas 全屏模式原型

灵犀（办公 Agent）Canvas 能力的全屏模式静态交互 Demo：在分屏编辑版基础上，增加全屏模式下的悬浮输入框与全屏回复气泡，参考 Kimi / Codex 的沉浸式文档 + 悬浮对话入口形态。

## 打开方式

直接访问在线地址（GitHub Pages）：

https://angelopku.github.io/lingxi-canvas-full/

或本地打开 `index.html`（零依赖、无构建，双击即可）。

## 能力清单

- 全屏模式：Canvas 占满窗口，底部悬浮紧凑输入框（单行、＋/Pro 模式/发送）
- 全屏回复落点可在设置切换：A 发送后回分屏看完整流程 / B 保持全屏、输入框上方浮单条流式回复气泡（可收起为「展示上一条消息」胶囊栏）
- 全屏下选区链路完整可用：划选 → 悬浮工具栏 → AI 编辑 → 发送/添加
- 分屏版全部能力：文档卡片多 tab、三组件编辑视图、选区 AI 编辑、编辑中反馈、草稿切换保护
- 可选接入 DeepSeek 真实修改选区内容（设置中配置 API Key，含内部默认 Key 一键填入）

## 说明

本 Demo 为交互示意：文档内容为 mock；未配置 API Key 时 AI 处理与文件更新以固定时长模拟，配置后选区修改调用 DeepSeek 真实执行。
